Album Digital.
De conservar recuerdos a diseñar un producto reutilizable.

El proyecto comenzó en 2025 como una solución real para organizar fotografías y videos familiares. La evolución técnica no consistió solo en mejorar una galería: consistió en aprender a separar aplicación, datos, privacidad, historia y producto.

Abrir producto públicoVer reconstrucción sanitizadaCódigo público

El problema original era real

Fotografías y videos personales estaban dispersos y necesitaban una forma sencilla de organizarse, recorrerse y compartirse. La primera respuesta fue construir una aplicación web funcional, no una maqueta.

Necesidad

Memoria digital accesible

Una interfaz web cronológica para navegar fotografías y videos sin depender de una red social.

Primera implementación

HTML + CSS + JavaScript + GitHub

Galería responsive, videos, lightbox, navegación y carga dinámica desde estructura de repositorio.

Infraestructura

GitHub Pages

El repositorio funcionó también como mecanismo de publicación y distribución web.

Limitación detectada

Código y contenido estaban demasiado acoplados

La solución funcionaba, pero mezclar medios familiares, navegación y aplicación impedía reutilizarla de manera segura como producto público.

La evolución fue una decisión de arquitectura

La historia verificable del proyecto se conserva, pero la implementación pública actual evita trasladar medios familiares al producto.

Privacidad como requisito de producto

Regla aplicada al lanzamiento: el contenido familiar real no se copia al portafolio, no se usa como recurso gráfico por defecto y no se enlaza como destino profesional principal. El lanzamiento utiliza el producto público y la reconstrucción sanitizada.

RAW privado

Fotografías, videos, documentos y contexto familiar pertenecen a almacenamiento privado.

Historia verificable

Se conserva la procedencia técnica, fechas y decisiones sin necesitar publicar el contenido personal.

Demo pública

La reconstrucción legacy usa datos ficticios locales y reproduce conceptos de interfaz sin consultar medios familiares.

Qué demuestra profesionalmente

El valor del caso está en el recorrido de resolución y no solo en el resultado visual.

Desarrollo web práctico

  • HTML, CSS y JavaScript.
  • Diseño responsive.
  • Render dinámico y lightbox.
  • Publicación con GitHub Pages.

Arquitectura de información

  • Separación entre interfaz, comportamiento, configuración y contenido.
  • Organización cronológica y por categorías.
  • Documentación de evolución y procedencia.

Privacidad y migración

  • Distinguir evidencia histórica de producto actual.
  • No reutilizar automáticamente datos personales.
  • Reconstruir una demo sanitizada en lugar de copiar el original.

Pensamiento de producto

  • Convertir una solución específica en una base reutilizable.
  • Identificar acoplamientos y límites del primer prototipo.
  • Definir roadmap sin presentar trabajo futuro como funcionalidad terminada.

Cómo se usa en el nuevo lanzamiento

Album Digital funciona como una de las piezas que conectan la historia personal con la trayectoria profesional: demuestra que el regreso a tecnología empezó resolviendo problemas concretos y evolucionó hacia sistemas con mejores reglas de privacidad, documentación y continuidad.
