¿Qué quieres hacer?

Elige una opción, copia el comando y pégalo en un chat nuevo. ROOT resuelve el contexto desde fuentes vigentes. La consola pública muestra solo accesos genéricos y evidencia sanitizada; la operación privada permanece fuera de esta superficie.

Accesos rápidos

Copia el comando que corresponde a lo que necesitas. Al entrar, el chat debe indicar el nivel actual, mostrar opciones numeradas, RECOMENDADO AHORA y una salida para regresar a ROOT.
